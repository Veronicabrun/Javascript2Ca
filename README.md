# UnityYoga - Front-end for Social Media Platform

## Description
UnityYoga is a front-end project for a social media application that allows users to create, view, edit, and delete yoga-related posts. This project is built using HTML, CSS, JavaScript, and utilizes the **Noroff API** to fetch and manage data.

## Features
- **User registration and login**: Users can register an account with a @noroff.no or @stud.noroff.no email address and log in to access the application's features.
- **View posts**: Users can view posts in a feed.
- **Filtering and searching**: Users can filter and search through posts.
- **Create, edit, and delete posts**: Users can create, edit, and delete posts they have created.
- **Responsive design**: The application is responsive and works on both desktop and mobile devices.

## Technologies Used
- **HTML**: For structuring the web pages.
- **CSS** (and SCSS): For styling and design.
- **JavaScript**: For interactivity and dynamic content.
- **Bootstrap**: For responsive design and UI components.
- **Font Awesome / Bootstrap Icons**: For icons.
- **Noroff API**: For fetching data.
